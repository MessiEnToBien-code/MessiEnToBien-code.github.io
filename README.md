# MessiEn ToBien

Página estática (HTML + CSS + JS, sin instalación).

## Publicar en GitHub Pages
1. Creá un repositorio nuevo en GitHub.
2. Subí todo el contenido de esta carpeta a la raíz del repo (`index.html`, `img/`, `.nojekyll`).
3. En el repo: Settings → Pages → Source: "Deploy from a branch" → Branch `main` / carpeta `/ (root)` → Save.
4. En un par de minutos queda en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

## Agregar sus redes
Abrí `index.html`, buscá `var REDES` y pegá los links entre las comillas. Los que dejes vacíos no se muestran.
